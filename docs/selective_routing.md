# Selective Routing — Раздельное туннелирование

## Что это?

Selective Routing позволяет направлять часть трафика клиента через VPN-туннель, а остальной — напрямую через провайдера.

## Режимы работы

### `vpn_mode = "general"` (Рекомендуемый)

Весь трафик идёт через VPN. Сайты из списка `exclusions` — напрямую.

**Когда использовать:** Стандартный сценарий для клиентов в РФ/Китае. Все заблокированные ресурсы работают, банки и госсервисы — напрямую.

### `vpn_mode = "selective"`

Весь трафик идёт напрямую. Только сайты из `exclusions` — через VPN.

**Когда использовать:** Когда клиент хочет разблокировать только конкретные ресурсы, а остальное использовать напрямую.

## Настройка

Список исключений хранится в `exclusions.txt` (по одному домену на строку):

```
sberbank.ru
*.sberbank.ru
gosuslugi.ru
*.gosuslugi.ru
```

При установке `install_script_win.ps1` загружает этот список с GitHub и вписывает в `config.toml` клиента.

## Поддержание актуальности

Список `exclusions.txt` нужно обновлять при появлении новых блокировок. Обновите файл в репозитории — и при следующей переустановке клиента он подтянет актуальный список.
