# Что делать, если VPN не работает

## Быстрая диагностика

### 1. Проверьте интернет-соединение
Откройте любой сайт (например, google.com). Если интернет не работает — VPN не сможет подключиться.

### 2. Перезагрузите компьютер
В 80% случаев это решает проблему. Служба VPN перезапустится автоматически.

### 3. Проверьте статус службы
1. Нажмите `Win + R`, введите `services.msc`
2. Найдите службу **TrustTunnelClient**
3. Статус должен быть **Работает** (Running)
4. Если нет — нажмите правой кнопкой → **Запустить**

### 4. Если ничего не помогло
Свяжитесь с вашим техником поддержки. Подготовьте следующую информацию:
- Дата и время, когда проблема началась
- Есть ли доступ в интернет без VPN
- Появляется ли какая-либо ошибка (скриншот)
