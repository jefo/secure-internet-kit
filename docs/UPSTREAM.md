# Upstream

This repository is an operations layer around [TrustTunnel](https://github.com/TrustTunnel/TrustTunnel), an open-source VPN protocol and endpoint originally developed by AdGuard VPN.

- Endpoint: https://github.com/TrustTunnel/TrustTunnel
- Client: https://github.com/TrustTunnel/TrustTunnelClient
- Flutter client: https://github.com/TrustTunnel/TrustTunnelFlutterClient
- Configuration reference: https://github.com/TrustTunnel/TrustTunnel/blob/master/CONFIGURATION.md

The upstream project owns the protocol, the endpoint binary, the client libraries, and the upstream documentation. This repository contains deployment, hardening, client onboarding, and operations scripts.

Upstream components keep their own licenses. Check the upstream repository before redistributing binaries.
